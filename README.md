# OpenCode Orchestrator

Харнес для OpenCode V2. Пользователь ведёт задачи из главного чата. Каждую задачу выполняет своя корневая сессия OpenCode в отдельном worktree, а отдельный процесс runtime ведёт маршрут задачи, вопросы человеку в панели TUI и восстановление после сбоев.

Состояние: кода нет. Реализация первой поставки удалена 25 ноября 2026 года, новая пишется с нуля. Документы ниже остаются основой для неё и правятся под новую реализацию.

Удалённая реализация лежит в истории: тег `v0.1.0` (первая поставка, предварительный релиз) и коммит `b1eae7a` (последнее состояние с автозапуском runtime). Что она успела проверить и какие решения приняты по её итогам, записано в [плане первой поставки](docs/first-delivery.md). Ещё более ранняя реализация удалена 23 ноября 2026 года, её итоги в [протоколе приёмки](docs/research/acceptance-2026-11-20.md).
